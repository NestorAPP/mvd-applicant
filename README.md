# Абитуриент МВД

Приложение для абитуриентов вузов МВД России.

## Возможности

- **Калькулятор** — расчёт баллов за вступительные испытания по физической подготовке (приказ МВД России № 44 от 02.02.2024, п. 343.4).
- **Техника** — описание правильного выполнения упражнений.
- **Видео** — ссылки на видео с правильной техникой силовых упражнений.
- **Подготовка** — рекомендации и генератор программы тренировок.

## Нормативы

- Подтягивание на перекладине (юноши)
- СКУ — силовое комплексное упражнение (девушки)
- Бег 100 метров
- Бег 1000 метров

## Группы предназначения

- 1-2 группа
- 3-4 группа

## Технологии

- Kotlin
- Jetpack Compose
- Material 3

## Сборка

APK собирается автоматически через GitHub Actions при каждом коммите в ветку `main`.
Готовый APK доступен во вкладке **Actions** репозитория.
